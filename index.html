How to use the files

  1. Download the SVG (or the ZIP) and open the SVG in Affinity.
  2. The layers are named (categories, scores, “07 Accountability”, Wedge, Rating 1–5, Number, Label) and the text stays editable in PT Sans.
  3. Save it as an Affinity document (.af) if you want to keep editing it.
  4. In “original position” mode, cluster and slice files line up with overview.svg and score files with overview-scores.svg when stacked.
  5. PNG and JPG files are for slides and web use; they include PT Sans, so text is correct anywhere.
